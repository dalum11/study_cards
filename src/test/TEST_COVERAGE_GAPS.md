## Приоритеты автотестирования
### Контроллер
Самый критичный модуль, так как API является входной точкой в приложение. Низкое покрытие будет означать высокий риск 
(баги, несоблюдение контракта, нарушение взаимодействия с БД)

### Сервис
Критичен, так как проверяет бизнес-логику. Ошибки в бизнес-логике могут повлечь за собой издержки 

## Обновление отчёта
### Как обновить этот документ
1. Запустить отчёт:
```bash
   ./mvnw clean test jacoco:report
   open target/site/jacoco/index.html
```

2. Посмотреть проценты по пакетам
3. Обновить таблицу выше
4. Отметить выполненные пункты [x]
